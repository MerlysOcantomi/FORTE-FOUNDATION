# Forte Foundation

Biblioteca interna de bloques reutilizables y versionados del ecosistema Forte.

Los bloques se **copian** a cada producto (Mission Control, 7F, Finesse, SKINA y futuros productos); no existe una dependencia runtime central compartida.

Este es el commit inicial del repositorio. El bootstrap completo (visión, principios, decisiones, especificaciones, schemas y catálogo) llega mediante pull request, siguiendo la regla de trabajo del ecosistema: PR → revisión → `main`.
